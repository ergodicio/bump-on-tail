# Methods: kinetic and fluid solvers used in the parameter sweeps

This note documents how the kinetic and fluid equations are actually solved
in `bot/sweep.py` and `bot/sweeps/*.py` — the dispersion sweep and the five
time-domain sweeps (`sweep_timedomain`, `sweep_u2_timedomain`,
`sweep_hp_beta`, `sweep_singlemode`, `sweep_twomode[_growing]`,
`sweep_inference`). Units throughout: `omega_p = v_b = 1`.

## 0. Normalizations and notation

Two physical scales are fixed to `1` throughout (`bot/kinetic.py`,
`bot/fluid.py`): the background plasma frequency `omega_p` and the beam
thermal speed `v_b`. Every other quantity in this document and in the code
is dimensionless in these units:

| Quantity | Normalization |
|---|---|
| Time `t` | units of `omega_p^{-1}` |
| Velocities `u_b`, `s=v-u_b`, `xi_b` | units of `v_b` |
| Wavenumber `k` | units of `omega_p/v_b`, so `k u_b`, `k s`, `xi_b=(omega-k u_b)/k` are dimensionless |
| Frequency `omega` | units of `omega_p`; `gamma=Im(omega)>0` growing, `<0` damped |
| Density ratio `eps = n_b/n_0` | dimensionless (`n_0`=bulk, `n_b`=beam density) |
| Bulk fields `u`, `E` | `u = u_phys/v_b`, `E = e E_phys/(m_e omega_p v_b)` — derived in §0.1, not asserted |
| Beam moments `U_n = ∫ s^n F(s) ds`, `F=f_{b1}/n_b` | `U_0`=fractional beam-density perturbation, `U_1`=density-weighted beam-frame velocity perturbation, etc. — normalized to *beam* density `n_b`, not `n_0`, so `eps` only appears where beam moments couple into the bulk equations (§1.1), never inside the hierarchy itself |
| Maxwellian moments `M_k = ∫ s^k F_0(s) ds` | fixed constants from the *equilibrium* `F_0(s)=(1/sqrt(pi))exp(-s^2)`: `M_0=1, M_1=0, M_2=1/2, ...` |
| Perturbation amplitude `amp` | sets every IC, typically `|E(0)|=amp` (e.g. `1e-3`); every system here is exactly linear or homogeneous-degree-1 in its closure, so `overshoot`/RMSE results are `amp`-independent |
| Plasma dispersion function `Z(xi)=i sqrt(pi) w(xi)` (Faddeeva `w`) | `Z'(xi)=-2(1+xi Z(xi))`; every closure is built from this `Z'`: `beta(xi)=xi^2-1/Z'(xi)`, `alpha(xi)=xi^3-xi/Z'(xi)`, `alpha4(xi)=xi^4-(xi^2+3/2)/Z'(xi)` |

### 0.1 Deriving the bulk-field normalization

Rather than asserting that the bulk species' charge `e`, mass `m_e`, and
density `n_0` are "set to 1," the dimensionless `u` and `E` used everywhere
in this document and in `bot/fluid.py` follow by direct substitution into
the *physical* bulk equations (source notes §1, eq. 1–3):

```
m_e n_0 d_t u_phys = -e n_0 E_phys          (bulk momentum)
d_t E_phys = e n_0 u_phys / eps_0           (Ampere's law, bulk only)
omega_p^2 := e^2 n_0 / (eps_0 m_e)          (definition of the plasma frequency)
```

Substitute `t = that/omega_p` (so `d_t = omega_p d_that`) and define

```
u = u_phys / v_b,         E = e E_phys / (m_e omega_p v_b)
```

The bulk momentum equation becomes
`omega_p v_b d_that(u) = -(e/m_e) E_phys = -omega_p v_b E`, i.e.
`d_that u = -E` — the `v_b` and `omega_p` factors cancel completely on both
sides, with no assumption needed. The bulk-only Ampere's law becomes
`omega_p (m_e omega_p v_b/e) d_that(E) = e n_0 v_b u / eps_0`, i.e.
`d_that E = [e^2 n_0/(eps_0 m_e omega_p^2)] u = u` exactly, because the
bracketed factor is `omega_p^2/omega_p^2 = 1` by the *definition* of
`omega_p` above — again no constant is independently set to 1; the
cancellation is forced by what `omega_p` already means. The beam-coupling
term `-eps(u_b U_0+U_1)` in `d_t E` is generated by the same `E`
normalization applied to the beam current (§1, §3); together,
`u = u_phys/v_b` and `E = e E_phys/(m_e omega_p v_b)` are the unique
nondimensionalization that makes the coupled bulk system unit-coefficient
in `(t,k,u_b)` normalized as in the table above. (Verified symbolically
with `sympy` for both equations above; see chat history.) This is the same
construction as the source notes' own `Phihat = e Phi/(m_e v_b^2)` for the
potential — `E` is to `Phi` as our nondimensionalized field is to theirs,
related by `E = -ik Phihat` in Fourier space (§0.2).

### 0.2 Correspondence with the original derivation

The physics in §1–3 originates from a separate hand-derivation
("*Bump-on-tail minimal closure model*" notes) that sets up the same beam
+ bulk system starting from the field equations and Vlasov equation in
physical units, then works in a normalized potential `Phihat` rather than
the field `E`. The two notations agree term-for-term once the following
dictionary is applied:

| Their symbol | Their definition | Our symbol / relation |
|---|---|---|
| `t-bar = omega_pe t` | normalized time | our `t` (we set `omega_p=1` from the start, so `t-bar` *is* our `t`) |
| `s = (v_x-u_b)/v_b` | beam-frame velocity | identical (`v_b=1` here, so numerically the same) |
| `xi_b = (omega-k u_b)/(k v_b)` | eigenmode ratio | identical (`v_b=1`) |
| `M_n = n_b^{-1} ∫ ds s^n f_{b0}` | equilibrium moments | identical to our `M_k` |
| `U_n = n_b^{-1} ∫ ds s^n f_{b1}` | beam moments | identical to our `U_n` |
| `n_b/n_0` | beam-density ratio | our `eps` |
| `Phihat = e Phi/(m_e v_b^2)` | normalized electrostatic potential | `Phihat = i E / k`, i.e. `E = -ik Phihat` — the standard `E=-d_x Phi` relation in Fourier space (derived below) |
| bare `k` in their §5.1 ODEs | left as "normalizations? k?" (unresolved in the source notes) | resolved here: it is the same dimensionless `k` (units `omega_p/v_b`) defined above |
| `Z(xi_b) = (1/n_0b) ∫ ds f_0b/(s-xi_b)` | generalized dispersion function | same Fried–Conte/Faddeeva convention as our `Z(xi)` |

**Deriving `Phihat = iE/k`.** Their moment recurrence (eigenmode form,
their eq. 15) is `xi_b U_n - U_{n+1} = n Phihat M_{n-1}`. Taking the same
recurrence from our own time-domain hierarchy (§1.1),
`d_t U_n = -ik u_b U_n - ik U_{n+1} + n M_{n-1} E`, and substituting the
single-eigenmode ansatz `d_t -> -i omega` gives, after rearranging with
`xi_b = omega/k - u_b`:

```
xi_b U_n - U_{n+1} = (i n M_{n-1} / k) E
```

Matching this to their `n Phihat M_{n-1}` term-for-term gives
`Phihat = iE/k` exactly — confirmed for every `n` (not just one), since the
coefficient of `n M_{n-1}` must agree identically. This is used in §3.5 to
translate every formula written in `Phihat` into our `E`-based equations.

## 1. Physical setup

Cold background plasma (density `n_0`, fluid moments `u`, `E`) plus a warm
beam (density `n_b`, drift `u_b`, thermal width `v_b = 1`), `eps = n_b/n_0`.
Linearized, single Fourier mode `k`. Beam velocity-space moments
`U_n = <s^n δf_b>` in the beam frame (`s = v - u_b`); bulk obeys cold-fluid
momentum + Ampère's law:

```
d_t u   = -E
d_t E   = u - eps (u_b U_0 + U_1)
```

The beam moment hierarchy from linearized Vlasov + integration by parts is
exact and not closed:

```
d_t U_n = -ik u_b U_n - ik U_{n+1} + n M_{n-1} E,    M_k = <s^k>_Maxwellian
```

(`M_0=1, M_1=0, M_2=1/2, ...`). Every solver below either truncates this
hierarchy with a *closure* for the highest moment, or discretizes velocity
space directly to get the kinetic answer with no closure at all.

### 1.1 Derivation of the beam moment hierarchy

Start from the same linearized beam-frame Vlasov equation used in §2.1 for
the perturbed beam distribution `F(s,t) = f_{b1}(s,t)/n_b`, `s = v - u_b`:

```
d_t F + ik(u_b+s) F = -E dF_0/ds,    F_0(s) = (1/sqrt(pi)) exp(-s^2)
```

(`F_0` is the equilibrium beam Maxwellian normalized to unit beam density,
`v_b=1`.) Define the `n`-th velocity moment `U_n(t) = ∫ s^n F(s,t) ds`.
Multiply by `s^n` and integrate over `s`:

```
d_t U_n + ik u_b U_n + ik ∫ s^{n+1} F ds = -E ∫ s^n (dF_0/ds) ds
```

The streaming term `ik s F` produces `ik U_{n+1}` on the left — every
moment equation couples to the *next* moment, which is why the hierarchy
never closes on its own: truncating at any finite `N` always leaves
`U_{N+1}` undetermined, and supplying it is exactly the job of a closure
(§3). On the right, integrate by parts in `s` (the boundary term vanishes
because `F_0 -> 0` as `s -> ±infinity`):

```
-E ∫ s^n (dF_0/ds) ds = -E [s^n F_0]_{-infinity}^{infinity} + E n ∫ s^{n-1} F_0 ds
                       = n M_{n-1} E,     M_k := ∫ s^k F_0(s) ds
```

`M_k` are moments of the *equilibrium* Maxwellian only (not of the
perturbation `F`), so they are known constants computable once from the
Gaussian `F_0`: `M_0=1` (normalization), `M_1=0` (odd integrand against an
even `F_0`), `M_2=1/2` (variance of `F_0`, since `v_b=1` makes
`F_0=(1/sqrt(pi))e^{-s^2}` a Gaussian of variance `1/2`), and so on
(`maxwellian_moment(k)` in `bot/closures/pade.py`, which returns
`(2j)!/(4^j j!)` for `k=2j` and `0` for odd `k`). Putting the two pieces
together gives exactly the moment hierarchy quoted above:

```
d_t U_n = -ik u_b U_n - ik U_{n+1} + n M_{n-1} E
```

Two structural facts fall straight out of this derivation and recur
throughout the closures in §3:

- **Only `n=1` is forced directly by `E`** (`d_t U_1 = -ik u_b U_1 -
  ik U_2 + M_0 E`, `M_0=1`); the `n=0` equation has *no* `E` term at all
  (`d_t U_0 = -ik u_b U_0 - ik U_1`, matching `_direct_u2_rhs`/
  `_bilinear_rhs` in `closed_loop.py`), and every higher-`n` forcing term
  vanishes whenever `n-1` is odd, i.e. whenever `n` is even — purely a
  consequence of `F_0`'s even symmetry, independent of any closure choice.
- **`M_1=0` is why the bilinear closure (`U_3 = U_1 U_2/U_0`) is an exact
  algebraic identity rather than an approximation.** On a pure eigenmode
  (`d_t -> -i omega`, so every moment scales as the same `exp(-i omega t)`),
  the `n=1` recurrence reduces to `U_2 = xi_b U_1` with `xi_b = U_1/U_0`;
  applying the same relation one level up (`n=2`, where `M_1=0` keeps the
  forcing absent: `d_t U_2 = -ik u_b U_2 - ik U_3 + 2 M_1 E = -ik u_b U_2 -
  ik U_3`) gives `U_3 = xi_b U_2 = (U_1/U_0) U_2`, i.e. `U_3 = U_1 U_2/U_0`
  — the closure `_bilinear_rhs` uses, with no dispersion-function evaluation
  needed because the identity never referenced `Z'` or `beta` to begin with.

The bulk (cold-background) equations `d_t u = -E`, `d_t E = u -
eps(u_b U_0 + U_1)` are the linearized cold-fluid momentum equation and
Ampère's law; `eps(u_b U_0 + U_1) = eps ∫ (u_b+s) F ds` is exactly the
beam's contribution to the current density (the beam-frame zeroth moment of
`v F`), so the bulk and beam systems couple only through the field
equation — not anywhere inside the moment hierarchy itself.

## 2. Kinetic solver (ground truth)

Two independent kinetic representations are used, both in `bot/kinetic.py`:

- **Analytic dispersion relation** `kinetic_dispersion(omega, k, u_b, eps)`:
  `D = 1 - 1/omega^2 - (eps/k^2) Z'(xi_b)`, with `xi_b=(omega-k u_b)/k` and
  `Z'` the derivative of the plasma dispersion function (Faddeeva `wofz`).
  Roots are found by complex Newton iteration (`find_kinetic_mode`), with a
  step-size guard against overshoot. Used to Newton-refine eigenvalue
  estimates to machine precision.

- **`s`-space discretized Vlasov–Poisson** (`kinetic_system_sspace`): the
  perturbed beam distribution `F(s)` is sampled on a uniform velocity grid
  (`N_v=96` points, `s ∈ [-V, V]`, `V=6`), turning the Vlasov equation into a
  linear ODE system of dimension `N_v + 2` (state = `u, E, F[s_0..s_{N_v-1}]`).
  All eigenvalues come from a dense `np.linalg.eig`. Phase mixing across the
  velocity grid reproduces Landau damping for `t` less than the grid's
  recurrence time; the most unstable/least-damped Langmuir-like root is
  selected by filtering `Re(omega) ∈ [0.3, 3.0]` and taking the largest
  `Im(omega)` (`most_unstable_kinetic`), then Newton-refined against the
  analytic dispersion relation for precision.

### 2.1 Derivation and structure of the `s`-space matrix

`kinetic_system_sspace` (`bot/kinetic.py:76`) discretizes the linearized
Vlasov equation for the perturbed beam distribution directly in velocity,
rather than truncating a moment hierarchy. Work in the beam frame,
`s = v - u_b`, and define `F(s,t) = f_{b1}(s,t)/n_b` (perturbed beam
distribution normalized to beam density). The beam Maxwellian
`F_0(s) = (1/√π) e^{-s²}` (`v_b = 1`). Linearizing Vlasov for the beam
species against the self-consistent field `E`:

```
d_t F + ik(u_b + s) F = -E · dF_0/ds = E · (2s/√π) e^{-s²}
```

This is exact — no closure — because it is the full (linearized) Vlasov
equation in `s`, not a moment truncation. It is discretized by sampling `F`
on a uniform grid `s_j ∈ [-V, V]`, `j = 0..N_v-1` (`s_grid`, default
`N_v=96`, `V=6`, so `Δs = 2V/(N_v-1) ≈ 0.126`), giving the diagonal
free-streaming term and a forcing term per grid point:

```
d_t F_j = -ik(u_b + s_j) F_j + src_j · E,    src_j = (2 s_j/√π) e^{-s_j²}
```

— this is exactly `A[2+j, 2+j] = -ik(u_b+s_j)` and `A[2+j, 1] = src_j` in the
code. Each velocity grid point thus behaves as an independent, undamped
oscillator with its own real "ballistic" frequency `k(u_b + s_j)`, driven
only by `E`. Coupling back to the field closes the loop through Ampère's
law, where the beam current integral `eps(u_b U_0 + U_1) = eps ∫(u_b+s)F ds`
is evaluated by the same uniform grid via the rectangle rule:

```
d_t E = u - eps Σ_j (u_b + s_j) F_j Δs
```

i.e. `A[1, 2:] = -eps(u_b+s)Δs`. So the full `(N_v+2)`-dimensional matrix
`A` has a dense first column/row (the `u`–`E`–beam coupling) and a diagonal
block for the `N_v` velocity-grid oscillators — structurally a discrete
analogue of the van Kampen mode decomposition of the Vlasov–Poisson system:
the continuum of undamped ballistic modes (one per real velocity) becomes
`N_v` discrete real-frequency eigenvalues, while one (or a few) complex
eigenvalue(s) split off the real axis and correspond to the true Langmuir /
beam-unstable mode. Landau damping is reproduced only as the net effect of
destructive interference (phase mixing) across this discrete quasi-continuum
when summed back into `E`/`u`, not by any single eigenvalue having negative
imaginary part — except for the genuine discrete root, which does pick up a
true complex eigenvalue once `N_v` is large enough to resolve it.

### 2.2 Finite-`N_v` artifacts and why mode selection + Newton refinement matter

The discretization has two well-known finite-grid pathologies, both visible
in this code:

- **Grid recurrence.** Because phase mixing here happens on a *finite,
  uniformly-spaced* velocity grid rather than a true continuum, the
  destructive interference that produces apparent Landau damping is only
  approximate: it un-mixes (recurs) once the phase difference between
  adjacent grid points, `k Δs t`, reaches `2π`, i.e. at
  `t_recurrence ≈ 2π/(k Δs)`. Before that time the damped signal looks like
  genuine continuum Landau damping; after it, numerical recurrence
  contaminates the result. This bounds how long any kinetic trajectory from
  `kinetic_evolve` can be trusted, and is part of the motivation for fitting
  `gamma_eff` only late in the window but not arbitrarily late, and for
  keeping `N_v` large / `V` wide enough that `t_recurrence` comfortably
  exceeds the sweep's `t_end`.
- **Spurious eigenvalues and tiny continuum leakage.** `np.linalg.eig` on the
  full `(N_v+2)×(N_v+2)` matrix returns `N_v` real (or near-real)
  van-Kampen-like eigenvalues densely packed along the ballistic line
  `Re(ω) = k(u_b+s_j)`, plus the physical complex root(s). `most_unstable_kinetic`
  filters candidates to `Re(ω) ∈ [0.3, 3.0]` (a window known to contain the
  Langmuir-like branch, away from the beam-drift line and grid-edge
  artifacts) and picks the largest `Im(ω)` in that window as the starting
  guess, then Newton-refines it against the *analytic* dispersion relation
  `D(ω,k)=0` (§2, `find_kinetic_mode`) to remove residual grid-discretization
  error and reach machine precision. Even projecting onto the discrete
  eigenvector associated with the physical root leaves an `O(10^-14)`
  (floating-point-level) component along the nearby van Kampen continuum;
  because that component does not decay, it eventually dominates the true
  exponentially-decaying signal at late times for strongly Landau-damped
  cases (see the "Van Kampen observation" in `bot/paper/summary_u2.tex`,
  §Landau-damping eigenmode tests) — another reason late-time `gamma_eff`
  fits are windowed rather than taken at very long `t`.

`kinetic_peak` (`bot/sweep.py`) scans `k` over `[0.10, 1.20]` (80 points),
calls `most_unstable_kinetic` at each `k`, and returns the `k*` of maximum
growth rate — this `k*` is the operating point used by every time-domain
sweep cell.

**Kinetic time evolution** (`kinetic_evolve` in `bot/closed_loop.py`):
diagonalizes the same `s`-space matrix `A` once (`eigvals, evecs =
np.linalg.eig(A)`), projects the initial condition onto the eigenbasis, and
reconstructs `E(t)` as a sum of `exp(eigval·t)` terms — i.e. exact matrix
exponentiation via eigendecomposition, not numerical time-stepping. This is
exact for the linear, time-independent `A` and is what every closure's
`gamma_eff` is compared against.

## 3. Closures (the part the fluid system must supply)

All closures act on the same unclosed beam-moment hierarchy and differ only
in how they construct `U_{N}` from `(U_0, ..., U_{N-1})`.

- **Padé / Hammett–Perkins (`bot/closures/pade.py`)**: a fixed, k-independent
  linear closure `U_N = sum_i a_i U_i`. For `N=3`, `a` is the classic
  Hammett–Perkins (1990) rational closure built by matching the
  large-argument asymptotic of `Z'(xi)` (`1/xi^2 + 3/(2xi^4)+...`) and the
  small-argument imaginary part (Landau damping rate at `xi=0`). For general
  `N`, `a` solves a linear Taylor-matching system against `Z'(xi)` at
  `xi=0` (`_zprime_taylor`, `_Q_taylor`). Because `a` is fixed, the closed
  system `fluid_system(k,u_b,eps,a)` (`bot/fluid.py`) is a *linear*,
  k-dependent matrix and its modes are again obtained by `eigvals`/matrix
  exponential — same machinery as the kinetic solver (`pade_evolve`,
  `trace_fluid`).

- **Direct-β / direct-α (`bot/closures/u2.py`, `direct_alpha` in
  `closed_loop.py`)**: zero-parameter, *nonlinear* closures that apply the
  exact single-eigenmode kinetic formula at the instantaneous moment ratio,
  e.g. `U_2 = U_0 · beta(U_1/U_0)` with `beta(xi) = xi^2 - 1/Z'(xi)`, or
  `U_3 = U_0 · alpha(U_1/U_0)` with `alpha(xi) = xi^3 + xi/(sqrt(pi) Z'(xi))`.
  Exact on a pure eigenmode (where `U_1/U_0 = xi_b` identically); the
  resulting fluid system is nonlinear in the state and is integrated with
  `scipy.integrate.solve_ivp` (RK45, `rtol=1e-8, atol=1e-10`).

- **Bilinear closure**: `U_3 = U_1 U_2 / U_0`, the exact moment-recurrence
  identity that holds because `M_1 = 0`; also nonlinear, RK45-integrated.

- **Inference / naive / sim-trained NN closures (`bot/closures/inference.py`,
  `naive_nn.py`, `n4_nn.py`)**: an Equinox MLP maps moment ratios
  `(U_1/U_0, U_2/U_0)` (real/imag stacked, 4 real inputs) either to an
  inferred `xi_hat` (then `alpha(xi_hat)` is evaluated analytically via
  Faddeeva — "inference" closure) or directly to `alpha` itself ("naive"
  closure). Networks are trained offline (Adam + cosine LR decay, MSE loss
  on synthetic or simulation-trajectory data) and loaded from checkpoints in
  `bot/runs/*.eqx`. At evaluation time the closure is just a forward pass
  inserted into the same nonlinear RHS, RK45-integrated exactly as the
  direct closures above.

### 3.1 Why these closures are nonlinear (and what that costs)

Padé closures fix `a_i` once and for all, so `U_N = Σ a_i U_i` is *linear*
in the state and the whole system stays a constant matrix `A(k,u_b,eps,a)` —
diagonalizable once, propagated by matrix exponential. Direct-β/α, bilinear,
and NN closures instead recompute the closure coefficient at *every instant*
from the current moment ratios — `beta(U_1(t)/U_0(t))`, `alpha(U_1(t)/U_0(t))`,
or a network evaluation — so the closure itself is a nonlinear function of
the state, even though the underlying moment equations
`d_t U_n = -ik u_b U_n - ik U_{n+1} + n M_{n-1} E` are linear except at the
truncated row. There is no constant matrix to diagonalize, so these systems
cannot use the matrix-exponential trick and must be time-stepped.

### 3.2 RHS construction (`bot/closed_loop.py`)

Each nonlinear closure has its own `_*_rhs(t, y_real, k, u_b, eps, ...)`
function with an identical pattern:

1. **Unpack.** `scipy.integrate.solve_ivp` only handles real state vectors,
   so the complex state `y = (u, E, U_0, ..., U_{N-1})` is stacked as
   `y_real = [Re(y), Im(y)]` (length `2(N+2)`) and unpacked back to complex
   on entry: `y = y_real[:N+2] + 1j*y_real[N+2:]`.
2. **Evaluate the closure** to get `U_N` from the current `(U_0,...,U_{N-1})`:
   - *direct-β* (`_direct_u2_rhs`, N=2 state `(u,E,U_0,U_1)`):
     `U_2 = U_0 · beta(U_1/U_0)`.
   - *direct-α* (`_direct_alpha_rhs`, N=3 state `(u,E,U_0,U_1,U_2)`):
     `U_3 = U_0 · alpha(U_1/U_0)` — uses only `r_1 = U_1/U_0`, ignoring `U_2`
     as a closure input (mirrors how direct-β uses only `r_1` at N=2).
   - *bilinear* (`_bilinear_rhs`): `U_3 = U_1·U_2/U_0`, the exact algebraic
     identity that follows from the moment recurrence because `M_1=0` (no
     dispersion-function evaluation needed at all).
   - *inference* (`_inference_rhs`): compute both ratios `r_1=U_1/U_0,
     r_2=U_2/U_0`, run them through the MLP to get `xi_hat = model_xi(model,
     r_1, r_2)`, then set `U_3 = alpha(xi_hat)·U_0` using the *exact*
     analytic `alpha` — the network only supplies the effective `xi`,
     physics knowledge of `alpha`'s functional form is retained.
   - *naive* (`_naive_rhs`): same ratio inputs, but the MLP outputs `alpha`
     itself directly (`naive_predict_alpha`) — no analytic structure is
     imposed downstream.
   - *sim-trained* (`sim_evolve`): identical RHS/network architecture to
     naive; the only difference is the training data source (simulation
     trajectories rather than closed-form eigenmode samples — see §3.3).
   - *N=4 NN* (`_nn_n4_rhs`, `bot/closures/n4_nn.py`): state extends to
     `(u,E,U_0,U_1,U_2,U_3)`; the network takes three ratios
     `(r_1,r_2,r_3)=(U_1/U_0,U_2/U_0,U_3/U_0)` and outputs `alpha4` directly,
     closing `U_4 = alpha4·U_0`. With three ratio inputs the closure is, in
     principle, exactly invertible for a two-mode superposition (the
     "information-counting" argument in `n4_nn.py`'s docstring), unlike the
     N=3 NN closures which only see two ratios and are formally
     underdetermined off a single eigenmode.
   - All closures guard against `|U_0| < 1e-15` and return `U_N = 0` in that
     case, since `U_1/U_0` etc. are otherwise singular.
3. **Assemble `dy/dt`** from the (otherwise linear, unclosed) moment
   equations plus bulk equations `du=-E`, `dE = u - eps(u_b U_0+U_1)`, using
   the freshly closed `U_N`.
4. **Re-stack** `dy` into `[Re(dy), Im(dy)]` for `solve_ivp` to consume.

### 3.3 Integration and what differs between closures

All nonlinear closures share one integrator call:

```
solve_ivp(rhs, (t0, t_end), y0_real, t_eval=t_grid, args=(...),
          method="RK45", rtol=1e-8, atol=1e-10)
```

i.e. adaptive-step explicit Runge–Kutta 4(5) (Dormand–Prince) with tight
tolerances, identical across direct-β/α, bilinear, and all NN variants —
so differences in the resulting `E(t)` (and hence in fitted `gamma_eff` /
overshoot) are attributable to the *closure model*, not to integrator
settings. What differs between closures is purely:

- **Exactness on-manifold.** Direct-β, direct-α, and bilinear are exact
  reproductions of the kinetic moment recurrence *on a single eigenmode*
  (where the relevant ratio truly equals `xi_b`). Off-manifold (e.g. the
  generic `δE` IC, or mixed two-mode ICs) they extrapolate the same formula
  to an "effective" `xi` that is not the true `xi_b` of any mode — this
  extrapolation error, not integration error, is what the sweeps are
  designed to expose (cf. `bot/paper/summary_u2.tex`, "N=2 vs N=3 NN off
  eigenmode").
- **Training data and target.** The inference closure trains a network to
  predict `xi_hat` (2 outputs) and lets analytic `alpha(xi_hat)` carry the
  curvature of the true closure function; the naive closure trains a
  network to predict `alpha` itself (2 outputs) with no analytic scaffold;
  the sim-trained variant uses the same naive architecture but trains on
  moment ratios sampled from actual kinetic `s`-space simulation
  trajectories (`bot/train_simdata.py`) rather than closed-form
  eigenmode-sampled `xi` values, so its training distribution better
  matches the off-manifold states it will see at evaluation time. The N=4
  network uses three ratio inputs instead of two, trained the same way
  (Adam + cosine-decayed LR, MSE loss) on synthetic `xi`-sampled data.
- **Number of closure-relevant moments retained.** Direct-β/Pade-N=2 close
  at `U_2` (4-dim state); direct-α/bilinear/N=3-NN close at `U_3` (5-dim
  state); the N=4 NN closes at `U_4` (6-dim state) — each adds one more
  exact moment equation before the closure is invoked, so comparisons
  across `N` isolate how much an extra resolved moment buys before the
  unavoidable closure-error has to act.

### 3.4 Worked example: the direct-β system at `N=2`

This works through the direct-β closure concretely, end to end, including
actual numbers, to make §3.1–3.3 tangible.

**The closed system.** Truncating the moment hierarchy at `N=2` keeps
`(u, E, U_0, U_1)` as the four (complex) dynamical variables and closes
`U_2 = U_0 · beta(U_1/U_0)`, `beta(xi) = xi^2 - 1/Z'(xi)` (§3, `bot/closures/u2.py`).
Substituting this `U_2` into the `n=1` moment equation from §1.1 gives the
closed ODE system actually solved (`_direct_u2_rhs` in `closed_loop.py`):

```
d_t u   = -E
d_t E   = u - eps (u_b U_0 + U_1)
d_t U_0 = -ik u_b U_0 - ik U_1
d_t U_1 = -ik u_b U_1 - ik U_0 beta(U_1/U_0) + E
```

Three of the four equations are linear in `(u,E,U_0,U_1)`; only the last
term of the `U_1` equation, `beta(U_1/U_0)`, is a nonlinear function of the
state — this single term is the entire difference from a Padé closure (§3),
and it is what forces RK45 time-stepping instead of an eigendecomposition.

**Concrete numbers.** At the operating point used in `fig_manifold_transient`
(`u_b=4.0`, `eps=0.02`), `kinetic_peak` gives `k* = 0.2949` and kinetic
eigenfrequency `omega = 0.9468 + 0.0893j`, hence
`xi_b = (omega - k u_b)/k = -0.7898 + 0.3028j` and
`beta(xi_b) = 0.9270 + 0.4689j`.

**Why it is exact on the eigenmode.** If the state is started *exactly* on
the eigenmode (`U_1/U_0 = xi_b` at `t=0`, e.g. via `fluid_eigenmode_ic_u2`),
then `U_1/U_0` stays equal to `xi_b` for all `t` (every moment scales as
the same `exp(-i omega t)`), so `beta(U_1/U_0)` never changes and can be
*frozen* at the constant `b = beta(xi_b) = 0.9270+0.4689j`. Freezing it
turns the system linear, with constant matrix (state order `u,E,U_0,U_1`):

```
A = [[ 0,        -1,          0,        0      ],
     [ 1,         0,         -eps u_b,  -eps   ],
     [ 0,         0,         -ik u_b,   -ik    ],
     [ 0,         1,         -ik b,     -ik u_b]]
```

Diagonalizing this fixed `4x4` matrix gives four eigenvalues
`lambda`, with `omega = i lambda`:

```
omega in { -1.0021,  1.5243+0.0564j,  0.9468+0.0893j,  0.8905-0.1457j }
```

— one of the four eigenvalues reproduces the kinetic `omega = 0.9468+0.0893j`
*exactly* (to machine precision), because `beta(xi)` was constructed
(§3, `closures/u2.py`) to be the precise per-mode value that makes this
true for *every* `xi_b`, not just this one. This is the algebraic content
of "direct-β is exact on a single eigenmode": the closure doesn't merely
approximate the kinetic answer, it is defined as whatever value of `U_2/U_0`
forces the frozen-coefficient matrix above to have `omega` as an eigenvalue.
The other three eigenvalues are the system's remaining (non-physical)
fluid modes, irrelevant when the IC excites only the physical one.

**Off the eigenmode**, e.g. under the generic `delta-E` IC (§5;
`u=U_0=U_1=0, E=amp`), `U_1/U_0` is not constant and `beta(U_1(t)/U_0(t))`
must be re-evaluated at every RK45 step from the *instantaneous* ratio —
the system is genuinely nonlinear and the "frozen matrix" picture above no
longer applies. This is exactly what produces the transient behavior
explored in `fig_manifold_transient`: direct-β still tracks `gamma_kin`
correctly once the trajectory settles near the dominant eigenmode (because
`beta` is evaluated at whatever ratio the trajectory actually has, and that
ratio approaches `xi_b` as the unstable mode comes to dominate), but other,
non-eigenmode initializations can transiently probe `beta` far from `xi_b`.

**How it is actually solved.** `direct_u2_evolve` (`closed_loop.py`) stacks
the complex 4-vector into a real 8-vector (`[Re(u,E,U_0,U_1), Im(u,E,U_0,U_1)]`),
calls `scipy.integrate.solve_ivp(_direct_u2_rhs, (t0,t_end), y0_real,
t_eval=t_grid, args=(k,u_b,eps), method="RK45", rtol=1e-8, atol=1e-10)`,
and unpacks the result back to complex, returning `E(t)` (`y_complex[1]`).
`_direct_u2_rhs` itself does the unpack -> evaluate `beta(U_1/U_0)` (guarded
against `|U_0|<1e-15`, returning `U_2=0` in that case) -> assemble `dy/dt`
from the four equations above -> repack to real, on every RHS call the
adaptive-step solver makes.

### 3.5 Cross-check: §3.4 matches the source derivation, once normalized

The source notes (§0.2) independently arrive at the same direct-β system in
their own §5.1, with the same closure, written as:

```
d_t u   = -E
d_t E   = u - (n_b/n_0)(u_b U_0 + U_1)
d_t U_0 = -ik u_b U_0 - ik U_1
d_t U_1 = -ik u_b U_1 - ik U_0 beta(U_1/U_0) + E
```

— literally identical to the system in §3.4 once `n_b/n_0 -> eps` (§0).
The source notes leave the normalization of the bare `k` (and implicitly
`u_b`, `t`) as an open question ("*normalizations? k?*"); §0/§0.1/§0.2 resolves
it: `t` in units of `omega_p^{-1}`, `k` in units of `omega_p/v_b`, `u_b` in
units of `v_b` — exactly the units already used in `bot/closed_loop.py`,
confirmed by the eigenvalue match in §3.4.

**A sign to flag.** The source notes also give a kinetic comparison value,
`U_0 = -Phihat Z'(xi_b)` (their eq. 18), which differs by an overall sign
from what their *own* closure equation implies. Combining two of their
other equations: their eq. 17 (`U_0 = Phihat/(xi_b^2-a_1 xi_b-a_0)`) becomes,
in the exact-closure limit `a_1 xi_b+a_0 -> beta(xi_b)`,
`U_0 = Phihat/(xi_b^2-beta(xi_b))`; substituting their own eq. 25/26
relation `beta(xi_b)=xi_b^2-1/Z'(xi_b)` gives `xi_b^2-beta(xi_b)=1/Z'(xi_b)`,
hence

```
U_0 = Phihat * Z'(xi_b)        (from their eq. 17 + eq. 25, positive sign)
```

— the *opposite* sign from their eq. 18. Our own `fluid_eigenmode_ic_u2`
(§3.4) sets `U_0 = i Z'(xi_b) E/k`, which is exactly
`U_0 = Phihat Z'(xi_b)` under `Phihat=iE/k` (§0.2) — i.e. our code agrees
with their eq. 17+25 combination, not their eq. 18. Since §3.4 independently
verified this `U_0` reproduces the kinetic eigenvalue to machine precision
(the frozen-`beta` matrix diagonalization), eq. 18 in the source notes
appears to carry a stray minus sign (consistent with that document's own
"*make sure we have implemented the correct HP closure*" open item) rather
than indicating a real discrepancy between the two derivations.

## 4. Fluid time evolution

Two integration schemes are used depending on whether the closed fluid
system is linear or nonlinear in the state:

- **Linear closures (Padé, kinetic `s`-space system itself)**: build the
  constant matrix `A(k,u_b,eps,a)`, eigendecompose once, evolve by
  `y(t) = V exp(Λt) V^{-1} y(0)` — exact, no time-stepping error
  (`pade_evolve`, `kinetic_evolve`).
- **Nonlinear closures (direct-β/α, bilinear, NN-based)**: the closure
  introduces a state-dependent (nonlinear) term into the RHS, so the system
  is integrated with `scipy.integrate.solve_ivp` using adaptive-step RK45
  (`rtol=1e-8, atol=1e-10`), real/imag parts stacked into a real state
  vector since `scipy` works in real arithmetic.

## 5. Sweep procedures

All sweeps loop over a 2D grid `u_b ∈ linspace(3,10,8)` ×
`eps ∈ {0.01,0.02,0.05,0.10,0.15,0.20}` (dispersion/time-domain sweeps), or
fixed `(u_b, k)` with a swept mixing weight (two-mode sweeps). At each grid
point:

1. **Locate the operating point.** `kinetic_peak` finds `k*` (and reference
   eigenfrequency `omega`) where the kinetic growth rate is maximal, via the
   `s`-space eigensolver scan described in §2.
2. **Choose an initial condition.**
   - *Dispersion sweep* (`bot/sweep.py`): no time integration — the fluid
     dispersion is traced in `k` via `trace_fluid` (mode continuation: at
     each `k`, pick the closed-fluid eigenvalue nearest the previous
     kinetic eigenvalue) and `gamma_fluid` is read off directly at `k*`.
   - *Generic-δE sweeps* (`sweep_timedomain`, `sweep_u2_timedomain`,
     `sweep_hp_beta`): only `E(0) = amp` is nonzero (`amp=1e-3`); all moments
     start at zero. This excites every fluid eigenmode simultaneously
     (including spurious/non-physical closure modes), so it is the harsher
     "stress test" of a closure's off-manifold behavior.
   - *Eigenmode / mixed-eigenmode sweeps* (`sweep_singlemode`,
     `sweep_twomode[_growing]`): the IC is built from the kinetic system's
     own eigenvector(s) (`fluid_eigenmode_ic_*`), either a single mode or a
     weighted mix of two kinetic modes — this isolates how well a closure
     reproduces beating/mixing physics that is not a single eigenmode.
3. **Integrate** each system (kinetic reference + each closure under test)
   on a common time grid (`t ∈ [0, 60]`, 601 points, or 25-Landau-period
   windows for the eigenmode sweeps) using the linear (eigendecomposition)
   or nonlinear (RK45) scheme appropriate to that closure, per §4.
4. **Score the result.**
   - Growth-rate sweeps: fit `gamma_eff` from the late-time slope of
     `log|E(t)|` via `scipy.stats.linregress` over `t >= t_fit_min` (25),
     then report `overshoot = (gamma_fluid - gamma_kin)/gamma_kin`.
   - Eigenmode-IC sweeps: relative RMSE `||E_fluid - E_kin||_2/||E_kin||_2`,
     or `log10|gamma_fluid/gamma_ref - 1|` for the mixed-mode sweeps, against
     an analytic two-exponential reference `E_ref(t) = (1-w)e^{-i omega_1 t}
     + w e^{-i omega_2 t}`.
5. Results are saved as compressed `.npz` arrays in `bot/runs/`, shape
   `(n_u_b, n_eps)` (or the relevant 2D grid), and rendered by the matching
   `bot/figs/fig_*.py` driver scripts.

## 6. Summary of which solver is "ground truth" vs "approximation"

| Quantity | Method | File |
|---|---|---|
| Kinetic dispersion / growth rate | Faddeeva-based analytic `D(omega,k)`, Newton root | `kinetic.py` |
| Kinetic eigenmodes / time evolution | `s`-space discretized Vlasov, dense `eig`, matrix exponential | `kinetic.py`, `closed_loop.py` |
| Padé/HP closed fluid | Fixed linear closure, dense `eig`, matrix exponential | `closures/pade.py`, `fluid.py` |
| Direct-β/α, bilinear closures | Exact per-mode nonlinear closure, RK45 | `closures/u2.py`, `closed_loop.py` |
| NN closures (inference/naive/sim) | Equinox MLP forward pass inside RK45 RHS | `closures/inference.py`, `naive_nn.py`, `n4_nn.py` |
